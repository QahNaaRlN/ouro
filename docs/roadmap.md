Пользователь изменил приоритет: сначала локальный вход и общий MCP, затем готовые подключения, упрощение интерфейса и исправление замечаний к реальному приложению. Поручение об интеграции, публичном beta.3 и обновлении основной установки выполнено 03.11.2026. [Изменения статусной модели и контрактов](proposals/status-contract-followups.md) остаются только предложением для согласования; ни UI-пакет, ни публикация релиза их не активируют. Построение полной дорожной карты остаётся будущим пакетом с отдельными AC. Текущий контракт 0.1.2 формализует 18 tools, Flow, проходы, workspace context и ответы; batch tool и полный типизированный каталог event payload в него не входят. [Граница текущей версии](protocol-guide.md).

Дополнительные требования действующей методологии реализованы пакетом [OURO-ENG-000007](specs/methodology-recovery.md): отзыв/уточнение и исправление решения новыми фактами, read-only проекция на выбранном cursor, операторское восстановление после экстренного отзыва ключа. Физические Blocker и неизвестная остановка сохраняют отдельные guards; [сценарии и ограничения](methodology-guide.md).

Ouro-side пакеты alpha.1–14 реализованы и проверены в указанных границах; alpha.15 и первый локальный beta.1 прошли общий gate. Исторические CI и артефакты beta.2 сохраняются в [его выпуске](https://github.com/QahNaaRlN/ouro/releases/tag/v0.1.0-beta.2); собственные проверки и поставка beta.3 приведены выше и в строках 16–19. Нативный пакет Meridian остаётся открытым по конкретному RFC. Ограничения внешних интеграций документируются по фактической проверке; fixture или SDK-тест не считается live ChatGPT интеграцией. Встроенный LLM runner, файловые write/shell tools, production SSO/RBAC/tenancy, внешний PostgreSQL acceptance и публичное веб-развёртывание этими UI-пакетами не добавляются. Опубликованный GitHub prerelease и обновлённая локальная установка остаются отдельной границей от размещённого веб-сервиса. Каждый следующий пакет фиксирует собственные AC до кода.

Исправление входа в детальный процесс из дорожной карты — [OURO-ENG-000012](plans/roadmap-process-navigation.md): точная активная ревизия по клику/Enter/пробелу, явное пустое состояние, 2 новых + 10 прежних browser-сценариев; без изменения доменной истории.

Пользователь изменил приоритет: сначала любая локальная папка как проект, общий MCP и единый живой дашборд, затем готовое подключение Cursor и Claude. Следующий запланированный пакет — построение полной дорожной карты: спеки, зависимости, процессы, основания и правила полноты с человеческим рассмотрением. Текущий контракт 0.1.2 формализует 18 tools, Flow, проходы, workspace context и ответы; batch tool и полный типизированный каталог event payload в него не входят. [Граница текущей версии](protocol-guide.md).

Дополнительные требования действующей методологии реализованы пакетом [OURO-ENG-000007](specs/methodology-recovery.md): отзыв/уточнение и исправление решения новыми фактами, read-only проекция на выбранном cursor, операторское восстановление после экстренного отзыва ключа. Физические Blocker и неизвестная остановка сохраняют отдельные guards; [сценарии и ограничения](methodology-guide.md).

Ouro-side пакеты alpha.1–14 реализованы и проверены в указанных границах; alpha.15 ожидает общего gate. Нативный пакет Meridian остаётся открытым по конкретному RFC. Ограничения внешних интеграций документируются по фактической проверке; fixture или SDK-тест не считается live ChatGPT интеграцией. Встроенный LLM runner, файловые write/shell tools, production SSO/RBAC/tenancy, внешний PostgreSQL acceptance, release/tag и публичное развёртывание в этот срез не входят. Каждый следующий пакет фиксирует собственные AC до кода.

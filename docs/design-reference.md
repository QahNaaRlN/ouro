# Проверенные источники дизайна

Дата: 28.10.2026. Макеты изучались только на чтение.

- [Ouro.pen](https://app.pen.dev/s/ZybYRs27l7od_NZYYHASOr_1jXJ9YbL9nyNzQBJgmig) — структура: подтверждены семь экранов (дизайн-система, обзор, спецификация, решение узла, состояния, два варианта спецификации). Публичный холст прочитан обзорно; мелкие тексты, размеры и контроли не извлечены. Пиксельная копия не заявляется.
- [Meridian Figma](https://www.figma.com/design/dc5MYFfBVYH7AYKb0uXfJW) — стиль: прочитаны карта экранов, компоненты, каркас IDE, состояния, темы, сценарии MVP. Просмотрены реальные изображения рабочего места, детальной работы, галереи компонентов; значения получены из variables/styles.

| Назначение | Проверенное значение |
|---|---|
| Фон / subtle | `#101113` / `#181a1e` |
| Текст / вторичный текст | `#fafafa` / `#b4b8c2` |
| Граница / граница контрола | `#343841` / `#7c828e` |
| Выбор | `#626975` |
| Подложка успеха / ошибки | `#142a1e` / `#321c21` |
| Ошибка foreground | `#fca5a5` |
| UI / code | Inter / JetBrains Mono |
| Body / caption / section / code | 14 / 12 / 16 / 13 px |
| Интервалы / радиус контрола | 4, 8, 12, 16 px / 6 px |

Применены семейства button, field, tab, navigation item, status, context, notice, event row. Цвет сопровождается подписью/иконкой. Шрифты включены локально. Светлая тема прототипа — семантическая адаптация, не заявление об извлечении всех light-mode значений Figma. Контракт API/SSO/встраивания Meridian пока отсутствует.

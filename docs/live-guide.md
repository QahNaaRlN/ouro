# Живые обновления и безопасные черновики

alpha.4 · [SDD](specs/live-updates.md) · [TDD](plans/live-updates.md).

Внизу Human View отображается состояние подписки. «Живые обновления подключены» появляется после проверенного снимка, а не только открытия сетевого соединения. При разрыве остаются последние подтверждённые данные; после восстановления полная committed история загружается без дублей. Открытая спека, вкладка и камера не сбрасываются.

Ответ по Question, текст ревизии, основания приёмки и Flow draft держат наблюдавшуюся базовую версию. Внешнее событие сохраняет ввод/фокус/выделение, но не даёт автоматически принять новое ожидание старым evidence. Перед повтором после конфликта изучите изменения и явно обновите версию. Если другой человек уже ответил, ваш текст остаётся доступным для копирования рядом с записанным решением; повторная запись недоступна.

Если сервер вернул другую/откаченную историю, интерфейс показывает требование проверки и перезагрузки. Старые факты не заменяются молча. Поломанный frame не продвигает применённый cursor: клиент восстанавливается от последнего принятого снимка. Повторная доставка безопасна; поздний старый GET или неудачное старое recovery не отменяют новые данные/успешное подключение.

Roadmap фильтруется по агенту и типу **открытого** запроса. Совместный выбор проверяется по одному pending request актуальной ревизии. Граф сохраняет контекст приглушёнными узлами, таблица показывает совпадения; общий счётчик внимания не скрывается. Выбранная спека вне фильтра остаётся выбранной и обозначается подписью.

Транспорт — human-only `/api/stream`, SSE snapshots с committed cursor/Last-Event-ID. Сервер проверяет SQL примерно каждые500ms при спросе читателя, heartbeat15сек, подписка≤55сек с повторной авторизацией. Это простой SQL-based realtime, без внешнего broker. Поток не выдаётся агентскому ключу; агенты используют собственные MCP tools. Полный snapshot включает историю проекта; checkpoint/pagination и нагрузочный аудит ещё не выполнены. Техническая регистрация/presence агентов обновляется отдельным чтением8сек и не выдаётся за доменное событие.

Ориентиры: [WHATWG SSE](https://html.spec.whatwg.org/multipage/server-sent-events.html), [MDN SSE](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events), [Readable streams](https://developer.mozilla.org/en-US/docs/Web/API/Streams_API/Using_readable_streams), [Next Streaming](https://nextjs.org/docs/app/api-reference/file-conventions/route#streaming).

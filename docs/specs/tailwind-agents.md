# Tailwind 4 · подключения агентов

Дата: 2026-11-04. Ветка `codex/tailwind-agents`, база `48804f8`. Перенести конечное семейство `.agent-*` из `app/globals.css` в собственные readonly utility recipes `AgentsPanel`. Нативные общие элементы, заголовки, `.btn`/`.status` и другие families остаются отдельным ordinary debt.

Сохранить регистрацию и одноразовую выдачу ключа, все три формата конфигурации, настоящий clipboard/fallback, скрытие ключа, прочтение текущих регистраций, реальные created/lastSeen/revoked значения, отзыв и readOnly. Не менять HTTP/MCP, polling, handlers, генерацию credentials, сроки и формат дат. Статус присутствия не превращается в доказательство запуска агента. Fixtures используют только собственные ключи и профили; конфигурации/ключи не печатаются в логи и не входят в публичную документацию.

До source changes сохранить обе темы, desktop/mobile и основные варианты на реальных fixture данных. Одноразовый transient config нельзя повторно получить из API: для сравнения допускается test-only component renderer с неизменным зафиксированным настоящим ответом внутри собственного fixture. Его отличие от full-app proof отмечается явно. Производственный API ради снимков не расширяется.

Выход: все selectors этого семейства перенесены, смысл и AST handlers не изменены; visual/computed metrics сравнение, существующие browser сценарии регистрации/отзыва и проектных конфигураций, root/web strict types/builds, действительный compiler и architecture/style guards. Ledger изменяется только после review собственного переноса; прежний ordinary остаток не превращается в техническое исключение. Полный CI обязателен до merge в эпик.

29.10.2026 · SDD до изменения запуска. Запрос пользователя: подготовить репозиторий для локального запуска полной версии.

## Граница пакета

Одна опубликованная ветка содержит весь интегрированный прототип. Локальный режим запускается из чистого клона на рекомендованном Node.js 24 без отдельного PostgreSQL, Docker или API-ключей. Предыдущие worktree, preview и пользовательские БД сохраняются. Слияние предыдущих draft PR и production-развёртывание в пакет не входят.

## Критерии приёмки

1. README содержит точные clone/branch/install/dev команды, пригодные для PowerShell и терминалов macOS/Linux, URL и способ остановки.
2. `npm run dev` и `npm start` не используют POSIX-присваивание переменных или shell-склейку. Node launcher передаёт режим, аргументы и локальную конфигурацию непосредственно Next CLI, сохраняет loopback по умолчанию и поведение завершения процесса.
3. Путь проекта с пробелами и символами оболочки не меняет аргументы и не запускает команды оболочки. Ошибка CLI остаётся ненулевым кодом завершения.
4. Рекомендованная версия Node закреплена; минимальная версия согласуется с установленными Next.js docs. Установка воспроизводится по package-lock.json.
5. Чистый клон проходит установку и dev smoke; созданная запись сохраняется после остановки, сборки и production-запуска с той же отдельной БД.
6. README отдельно описывает dev и production; одновременные dev/build в одном `.next` и два процесса на одной PGlite-БД не предлагаются.
7. Необязательные E2E используют управляемый Playwright Chromium по умолчанию, допускают `CHROMIUM_PATH`, используют переносимые временные и artifact-пути. Команда установки браузера описана.
8. Запуск из Linux проверяется фактически. Отсутствующая Windows/macOS-среда не подменяется заявлением о нативной проверке; переносимость обеспечивается Node API и проверкой аргументов без shell.

## Основание

Прочитаны установленные Next.js 16.4.3 `01-app/01-getting-started/01-installation.md` и `01-app/02-guides/environment-variables.md`: Node.js >=20.9, Windows/macOS/Linux, команды dev/build/start, `.env` необязателен для приложения без внешних настроек. Уже реализованная БД использует Node `path` и PGlite; данные находятся в `.ouro/postgres` и исключены из Git.

Публичные ориентиры: [Next.js installation](https://nextjs.org/docs/app/getting-started/installation), [Node.js ES modules](https://nodejs.org/api/esm.html), [Playwright browsers](https://playwright.dev/docs/browsers). Исполняемые установленные пакеты и результаты smoke являются основанием проверки; поддержка ОС самим инструментом не считается нашим нативным OS-тестом.

# Beta.3: поставка принятого приложения

03.11.2026. Пользователь поручил развернуть принятый UI-срез `47b05f8`, актуализировать репозиторий и отдельно подтвердил публичный GitHub prerelease `v0.1.0-beta.3` с архивом. Основание: [правила выпуска](../../CONTRIBUTING.md), [первый выпуск](first-release.md), [UI-критерии](review-followups.md).

## Граница

Выпускается существующая цепочка PR20 / `918aadd` → `1e894ad` → `3aded9c` → `47b05f8`. Допускаются версия продукта, синхронизация живых руководств и исправление проверки веток для используемого `codex/<english-kebab-name>`. Протокол остаётся 0.1.2. [Новые статусные и контрактные правила](../proposals/status-contract-followups.md) не согласованы и не внедряются. Публикация локального приложения не создаёт облачный сервис.

## Критерии поставки

| ID | Проверяемый результат |
|---|---|
| B301 | Принятые UI-функции сохранены. Реальный CI release candidate проходит `checks` и `browser`; текущая ветка проходит соглашения без подмены окружения. Полный unit-набор, TypeScript, canonical protocol, standalone package, replay и production build проверены в их фактическом объёме. |
| B302 | Product version и lockfile согласованы на beta.3; protocol version не меняется. Общая история сохраняется, код интегрируется в dev и затем в main; старый beta.2 и его assets не заменяются. |
| B303 | Основная действующая установка и фактический каталог данных определены по живому процессу. Перед сменой версии сервер остановлен и вся остановленная БД скопирована. Копия проверена восстановлением; миграции007–009 не выданы за UI-only обновление. |
| B304 | Проверка копии старой БД новым кодом сохраняет идентификаторы проектов, исходные события и cursors, регистрации и состояние заданий. В рабочей установке используется явный прежний OURO_DATA_DIR; одно хранилище обслуживает один процесс. DoD и новые действия тестами на рабочей БД не создаются. |
| B305 | Новый source ZIP и protocol TGZ собраны только из принятого committed tree. Annotated tag, manifest и checksums указывают точный commit. Анонимно скачанные четыре release assets совпадают по размеру и SHA-256; приватные данные и runtime paths в архив не входят. |
| B306 | Чистая распаковка устанавливается и запускается штатным способом. На прежнем локальном порту доступна beta.3; HTTP/UI и сохранность данных проверены после переключения. Предыдущая установка и резервная копия остаются доступными; откат с потерей новых записей не выполняется автоматически. |

Факты, ограничения и итоги записываются в [журнал поставки](../plans/release-beta-3.md), без переноса прежних результатов на новый source SHA.

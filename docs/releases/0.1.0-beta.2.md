# Ouro v0.1.0-beta.2

Обновление первого знакомства с Ouro: меньше декоративных элементов, пошаговые подсказки на реальном интерфейсе и новый знак змеиного маршрута с узлами графа. Проекты, история и MCP-контракт сохраняются.

## Установить или обновить

На [странице версии](https://github.com/QahNaaRlN/ouro/releases/tag/v0.1.0-beta.2) выберите [ouro-0.1.0-beta.2-source.zip](https://github.com/QahNaaRlN/ouro/releases/download/v0.1.0-beta.2/ouro-0.1.0-beta.2-source.zip), распакуйте и запустите в папке с `package.json`:

```sh
npm run launch
```

Нужен Node.js 24 LTS с npm. Команда устанавливает зависимости, собирает production-версию и запускает Ouro. После `Ready` откройте `http://127.0.0.1:3000/projects` на том же компьютере и оставьте терминал открытым. Git, Docker и отдельный PostgreSQL для этого пути не требуются.

При обновлении остановите прежний сервер, сохраните базу и внешние файлы ключей агентов, затем настройте прежний `OURO_DATA_DIR` либо перенесите целиком остановленную базу. Новая распакованная папка сама не подхватывает старую историю. [Инструкция установки и переноса](../first-release-guide.md).

## Изменения

- **Меньше лишнего.** Убраны псевдопереключатель рабочего места, декоративный аватар, статические украшения и повторяющиеся лозунги. Имя участника, его роль, рабочие статусы и управление сохранены. «Проекты» в навигационной цепочке Human View открывает каталог.
- **Обучение по запросу.** Кнопка «Обучение» в каталоге и дашборде открывает подсказки с выделением текущей области и затемнением экрана. Есть переходы вперёд/назад, выход через Escape, пропуск и повторный запуск. Небольшое приглашение первого посещения не блокирует начало работы.
- **Реальный контекст.** Обучение объясняет папку, подключение агента, задачу/DoD, карту, человеческие решения и события. Подсказка процесса появляется, когда есть выбранная спека. Экскурсия не создаёт примеры и не отправляет команды работы или приёмки.
- **Новый знак Ouro.** Змея-Уроборос соединена с узлами и ветвлением графа: работа → факты → решение человека → следующая итерация. Масштабируемый знак используется в навигации и favicon.
- **Документация.** Добавлены [инструкция обучения](../guided-workspace-guide.md), [описание знака](../design/ouro-identity.md), [спецификация](../specs/guided-workspace.md) и [журнал реализации](../plans/guided-workspace.md).

## Совместимость и артефакты

Версия переносимого протокола остаётся **`0.1.2`**, **18 tools / 49 canonical JSON Schema**. База, события, модель полномочий и разграничение назначения, ACK, применения решения, результата и человеческой приёмки DoD не меняются.

Настройки обучения сохраняются только в браузере и содержат предпочтения показа подсказок. Работа с агентами и проектами не зависит от возможности записать эти настройки.

Набор выпуска: `ouro-0.1.0-beta.2-source.zip`, `ouro-protocol-0.1.2.tgz`, `release-manifest.json` и `SHA256SUMS`. Manifest указывает точный source commit и версии, checksums позволяют проверить скачанные файлы. Tarball протокола необязателен для запуска приложения; публикации пакета в npm registry этот выпуск не выполняет.

## Приёмка и границы

Локально прошли **368/368 unit/integration** и **82/82 production E2E**, без пропусков и flaky-повторов, а также TypeScript, production build,49 canonical schemas, database replay и независимая установка протокола **1/1**. Результаты RED→GREEN и независимого review описаны в [журнале обновления](../plans/guided-workspace.md). Финальный GitHub CI, source commit и проверка загруженных артефактов указаны на [странице выпуска](https://github.com/QahNaaRlN/ouro/releases/tag/v0.1.0-beta.2); сведения о beta.1 сохранены отдельно.

Среда приёмки — Linux/Node.js 24. Native Windows/macOS/WSL, пользовательские GUI и модельные аккаунты Cursor/Claude Desktop сохраняют прежние ограничения проверки. Настройка клиента и MCP-контракт сами по себе не подтверждают вход в модельный аккаунт.

Это локальная beta с доверенным оператором. Ouro не запускает модель автоматически и показывает факты, сообщённые по контракту. Файловые инструменты Ouro дают read-only контекст; собственные edit/shell-инструменты IDE принадлежат клиентам. Публичный архив не является размещённым веб-сервисом.

## Работа с данными и возврат

Перед остановкой сохраняется read-only fingerprint существующих проектов, историй и регистраций. Остановленный dataDir целиком копируется в приватный локальный служебный каталог вне Git. Проверка восстановления/миграции выполняется на отдельной копии и порту; рабочая база не используется тестовым сервером одновременно с основной установкой.

Новая установка получает прежний абсолютный OURO_DATA_DIR. После старта сверяются исходные события, cursors и регистрации; осмысленные новые миграционные записи фиксируются отдельно. Предыдущая папка приложения не удаляется. При проблеме новая версия останавливается, её данные сохраняются; восстановление старой копии допускается лишь после проверки отсутствия нужных новых пользовательских записей либо отдельного плана их сохранения.

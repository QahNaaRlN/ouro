## Реализация

Root финально одобрил SDD до source work. Pure port содержит ровно три reads и переиспользует canonical DTO. HTTP adapter владеет двумя существующими URLs, same-origin/no-store/abort и Zod; старый private identity helper удалён после перевода всех внутренних consumers, второй session schema не оставлен. Actual SQL-backed account/session handlers и local participant/workspace responses проходят новые schemas без изменения optional/null semantics; workspace/account взаимно не приводятся к чужому DTO.

Existing ProjectRuntimeProvider внедряет fixed `ouro:same-origin`, без hostEpoch override и второго QueryClient. Frontend shared context не имеет HTTP fallback. Два существующих identity controllers сохраняют ticket admission/accessEpoch; ключ дополнительно различает ownerId. Hooks/API различают disabled, unsupported, empty, initial fetch/error и current-scope refresh. New-scope данные не берутся из старого placeholder. Imperative waiters имеют refcounts, exact owned query identity и cancellation; освобождение одного waiter/observer не отменяет другого enabled reader. Все inactive observers без imperative leases позволяют отменить оставшуюся pending read. Manual refresh имеет отдельный lifetime admission; cancelled completion не подтверждает новый scope.

WorkspaceCatalog, ProjectSwitcher, Members catalog и legacy identity/account fallback используют только соответствующие semantic reads; hasAccount/session flags выбирают операцию. Остальные reads/writes/receipts/SSE не переносились. Form state не перемонтируется из-за environment replacement. Unsupported identity даёт конечное unavailable и не включает login fallback. Inline errors остаются главным UI-путём; safe reporter вызывается на query occurrence, независимо от throw/reject sink, без raw payload/message/credentials.

Отдельный browser fixture проверяет hooks/read-context replacement в bounded host composition. Он обслуживается только loopback Vite dev qualification config, не включается в production build и не открывает profile/DB/API. Actual web source configuration не предоставляет partial override. CI получает обязательный отдельный Playwright step. Existing controlled `tailwind-participants` account catalog fixture дополнен actual `slug/createdAt/createdBy`: прежний mock с одними id/name/role не представлял полный server contract. Schema не ослаблялась.

TanStack видит всех оставшихся readers; внешний panel unmount не уничтожает их ожидание. Чистый RED повторён после корректного awaiting failed fixture promise, затем **18/18 query tests GREEN**. Это новый bounded source delta, поэтому final affected suite/artifacts/browser повторяются.

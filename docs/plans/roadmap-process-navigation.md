# Дорожная карта → процесс · SDD/TDD

29.10.2026 · [Критерии](../specs/roadmap-process-navigation.md). База готового локального запуска — `9e700a6`.

Подтверждено чтением кода: mouse click графа только выбирает ID, таблица не выбирает process tab. Отдельный read-only browser probe подтвердил, что Enter не вызывает app-level click callback; cursor52→52. Все шесть исходных seed-спек созданы без flow. Ошибка навигации и отсутствие авторского плана — разные причины; исправление не создаёт фиктивную историю или схему.

До кода добавляются browser-регрессии: граф/таблица открывают точный активный процесс после просмотра другой ревизии, клавиатура открывает честное пустое состояние без записи событий. Затем выполняются GREEN, typecheck, production build и проверки затронутых пользовательских сценариев.

## RED → GREEN

Обе регрессии дали настоящий RED до изменения приложения: после mouse click и Enter регион «Процесс спецификации» не появлялся. Это соответствует сообщению пользователя, а не проблеме selector/среды.

После реализации отдельного `openSpecProcess` и обработчика клавиатуры — **2/2 GREEN**. Проверены граф → активная r1 → явный просмотр proposed r2 → другая спека через таблицу → исходная спека снова на активной r1. Проверены Enter и пробел, пустой flow, доступное создание схемы, неизменность revision/activeRevision/domain cursor и сохранение поиска при возвращении.

Независимое ревью поймало повторный `ariaLabel` в объекте узла; TypeScript подтвердил ошибку. Свойства объединены в одно с действием и статусом. Неуспешный промежуточный compile/browser прогон не считается GREEN. После исправления typecheck и обе browser-регрессии прошли. Историческая read-only панель, домен, seed и миграции не менялись.

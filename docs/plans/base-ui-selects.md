Каждый trigger имеет явное доступное имя. Значения, пустые варианты, disabled-условия, обязательность и доменные обработчики сохранены. Два учебных action-select сбрасывают выбор через controlled `value=""`; ручное присваивание DOM value удалено.

## Особенности интеграции

- JSX `<option>` используется только как объявление вариантов; общий компонент преобразует его в Base UI Items. Нативные option/select в DOM не создаются приложением.
- Вариант без value получает значение из текста (например Owner); пустая строка остаётся прежним значением фильтра или незаполненного поля. `Select.Value` явно показывает подпись такого варианта: библиотека по умолчанию считает пустую строку placeholder.
- Base UI отвечает за фокус, клавиатурный выбор, поиск по начальным буквам, disabled и форменный input/required. Обработчики получают строковое значение, без поддельного React/DOM-события.
- В обычном экране Portal использует библиотечный body по умолчанию. В нативном dialog — контейнер этого dialog, чтобы popup не оказался в inert-части документа. Для стандартного контейнера передаётся undefined: явный null в Base UI означает ожидание появления контейнера.
- Доменный движок, правила приёмки, версии, UNKNOWN/exact-retry, ключи и серверные контракты не изменены.

Основание: [Base UI Select](https://base-ui.com/react/components/select), [Forms](https://base-ui.com/react/handbook/forms), [Quick start / portals](https://base-ui.com/react/overview/quick-start); API дополнительно сверено с установленным исходным кодом1.9.0.

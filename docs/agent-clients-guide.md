# Подключить Cursor и Claude к Ouro

Рабочая версия — `0.1.0-alpha.15`, ветка `feat/client-onboarding`. Cursor, Claude Code и Claude Desktop используют тот же контракт `@ouro/protocol@0.1.2`: 18 tools, статические resources и 49 JSON Schema. Отдельный протокол для каждого клиента не нужен. [SDD](specs/client-onboarding.md) · [проверки](plans/client-onboarding.md) · [официальные источники](agent-clients-research.md).

## Сначала запустить Ouro локально

Установите Git, Node.js24 и нужный MCP-клиент. Для нового клона:

```sh
git clone --branch feat/client-onboarding --single-branch https://github.com/QahNaaRlN/ouro.git ouro-local
cd ouro-local
npm ci
npm run dev
```

После `Ready` откройте <http://127.0.0.1:3000/projects>, добавьте существующую папку и откройте её дашборд. Терминал Ouro должен оставаться запущенным. Если выбран другой порт, берите адрес из строки `Local` этого терминала.

Если репозиторий уже скачан, остановите его сервер через Ctrl+C и выполните из его папки:

```sh
git fetch origin feat/client-onboarding:refs/remotes/origin/feat/client-onboarding
git switch feat/client-onboarding
git merge --ff-only origin/feat/client-onboarding
npm ci
npm run dev
```

Явный refspec получает новую ветку и в прежнем клоне с `--single-branch`. Переключение и fast-forward сохраняют обычные проверки Git; сброса изменений или удаления `.ouro` нет. Существующая локальная история Ouro остаётся в своём каталоге данных.

Браузер, Ouro и клиентский stdio bridge должны видеть соответствующие локальные файлы и адрес. `127.0.0.1` относится к машине, где запускается клиент; адрес из облачной среды не открывает Ouro на вашем компьютере. В основном сценарии всё работает на одном компьютере и в одной ОС. Сочетание Windows-клиента с Node/путями из WSL требует отдельной настройки запуска, которую эти готовые профили не выполняют.

## Получить конфигурацию в дашборде

1. В блоке подключения выберите **Cursor**, **Claude Code** или **Claude Desktop**. Для одновременной работы нескольких клиентов создайте каждому отдельную регистрацию с узнаваемым именем.
2. Зарегистрируйте агента и сохраните одноразовый ключ в отдельный локальный файл вне репозитория и папки файлового контекста. Список регистраций не позволяет повторно прочитать ключ.
3. Укажите абсолютный путь в поле **«Файл ключа агента»**. JSON содержит путь к файлу, а не значение ключа. Файл должен быть доступен учётной записи, запускающей MCP-клиент.
4. Скопируйте или скачайте конфигурацию выбранного клиента. Путь к Node и bridge уже абсолютный, `OURO_URL` закреплён за выбранным проектом. Пустой или относительный путь ключа нужно исправить до экспорта.
5. Добавьте подключение в клиент по таблице ниже. Если файл настроек уже существует, добавьте только новую запись внутри его `mcpServers`, сохранив остальные подключения и поля. Генератор Ouro сам этот файл не редактирует.

Одноразовый ключ можно скрыть независимо от конфигурации. По пути уже сохранённого файла JSON можно получить повторно. Смена клиента меняет формат и инструкцию, а смена проекта требует его собственного endpoint и ключа. Название server entry содержит полный projectId, поэтому одинаковые первые символы разных ID не замещают подключения.

| Клиент | Куда добавить конфигурацию | Как проверить |
|---|---|---|
| Cursor | `.cursor/mcp.json` в открытой рабочей папке; для личного подключения во всех папках — `~/.cursor/mcp.json` | В Customize включить сервер и проверить его tools; диагностический вывод — Output → MCP Logs |
| Claude Code | `.mcp.json` в рабочей папке либо отдельный JSON-файл для `--mcp-config` | Запустить `claude` из рабочей папки, пройти запросы trust/server approval; открыть `/mcp` |
| Claude Desktop | Settings → Developer → Edit Config, ключ `mcpServers` в `claude_desktop_config.json` | Полностью завершить приложение и открыть снова; найти сервер и tools в управлении Connectors |

Рабочая папка Cursor/Claude Code может отличаться от папки, где установлен Ouro. Конфиг кладётся в папку проекта клиента, а абсолютный путь `args` продолжает указывать на `packages/mcp/bin/ouro-mcp.mjs` установленного Ouro. После переноса Ouro нужно заново получить конфигурацию с новыми путями.

## Cursor

Откройте нужную рабочую папку в Cursor и добавьте полученную запись в её `.cursor/mcp.json`. На Windows глобальное `~/.cursor/mcp.json` означает `%USERPROFILE%\.cursor\mcp.json`. Проектная и глобальная конфигурации могут объединяться; одна и та же server entry не должна случайно указывать на другой проект Ouro.

Профиль Ouro использует `type:"stdio"`, `command`, `args` и `env`. Cursor запускает bridge локально; тот обращается к уже работающему HTTP-серверу Ouro. Отдельный Secure MCP Tunnel для этого не требуется. В Customize включите сервер, затем попросите агента прочитать `ouro.get_context`. Подтверждайте разрешения инструментов, запрошенные клиентом; корпоративная политика может ограничивать доступ к MCP или loopback-сети. [Официальная настройка Cursor](https://cursor.com/docs/mcp).

## Claude Code

Профиль содержит `type:"stdio"` и ту же JSON-оболочку `mcpServers`. Основной вариант — добавить запись в `.mcp.json` рабочей папки, запустить там `claude` и рассмотреть запросы доверия к проекту и MCP-серверу. Не отключайте эти запросы ради подключения. Внутри сессии `/mcp` показывает состояние сервера и доступные действия.

Можно сохранить скачанный JSON в отдельный файл и загрузить его только для текущего запуска:

```sh
claude --mcp-config "/absolute/path/ouro-mcp.json"
```

На Windows подставьте свой абсолютный путь. Этот вариант не требует ручного экранирования JSON в командной строке и не записывает сервер в существующие настройки клиента. [Официальный флаг `--mcp-config`](https://code.claude.com/docs/en/cli-reference).

Для постоянного личного подключения команда `claude mcp add-json --scope local SERVER_NAME JSON_ENTRY` принимает **одну server entry**, не весь объект `mcpServers`. `local` ограничивает подключение текущей рабочей папкой; `--scope user` включает его во всех проектах, а `--scope project` сохраняет `.mcp.json`. Команды `claude mcp list` и `claude mcp get SERVER_NAME` помогают проверить конфигурацию и состояние; успешное добавление ещё не означает успешный вызов tool. [Официальные варианты и scopes](https://code.claude.com/docs/en/mcp).

Аккаунт Claude/провайдер модели настраивается в самом Claude Code по [официальной инструкции установки](https://code.claude.com/docs/en/setup). Ключ агента Ouro не является API-ключом Anthropic.

## Claude Desktop

Откройте **Settings → Developer → Edit Config** и добавьте запись в существующий `mcpServers`. Профиль Desktop использует canonical `command`, `args`, `env`, без обязательного `type` из профиля Claude Code.

Обычные пути файла:

| Система | Файл |
|---|---|
| macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Windows | `%APPDATA%\Claude\claude_desktop_config.json` |

Для другой установки или платформы точный путь берите через **Edit Config**; native-проверка приложения на каждой ОС в этом пакете не заявляется. Полностью завершите Claude Desktop, включая значок в системном трее на Windows, и откройте его снова. В управлении Connectors найдите Ouro, посмотрите инструменты и разрешите нужные вызовы. [Официальный локальный MCP-сценарий](https://modelcontextprotocol.io/docs/2026-07-28/develop/connect-local-servers).

Claude в браузере и Claude Desktop с локальным stdio — разные способы подключения. JSON локального Desktop нельзя установить просто в окно разговора claude.ai.

## Генератор из терминала

Из папки установленного Ouro команда печатает JSON и не изменяет существующие настройки клиента:

```sh
npm run --silent agent:config -- --client cursor --project-id 11111111-1111-4111-8111-111111111111 --url "http://127.0.0.1:3000/api/projects/11111111-1111-4111-8111-111111111111/mcp" --key-file "/absolute/private/ouro-cursor.key"
```

В этом примере замените тестовый projectId, точный URL и путь файла значениями своего проекта. Доступные профили: `cursor`, `claude-code`, `claude-desktop`, `chatgpt`. `--entry` допустим только с `--client claude-code` и печатает одиночный объект для `claude mcp add-json`; по умолчанию печатается весь wrapper `mcpServers`. Не передавайте значение ключа отдельным аргументом.

Для сохранения вывода в UTF-8-файл в POSIX-терминале можно добавить `> ouro-mcp.json`. `--silent` нужен, чтобы npm не добавил свой banner к JSON. На Windows проще скачать JSON из интерфейса: обычный редирект старого Windows PowerShell может выбрать другую кодировку. Перед добавлением записи в существующий файл объедините её с его `mcpServers`, не заменяя файл целиком.

## Передать работу и увидеть обновления

В дашборде выберите регистрацию клиента, заполните цель и проверяемые критерии и нажмите **«Начать работу»**. Работа остаётся queued до реального `ouro.confirm_started`. Скопируйте инструкцию задачи и передайте её агенту в выбранном клиенте с включённым Ouro.

Агент сначала читает `ouro.get_context`, проверяет назначение и точную ревизию, затем подтверждает разрешённое начало. Action, Question, Fork, Blocker, шаги Flow и результат он отправляет через соответствующие инструменты. Дашборд обновляется по подтверждённым событиям; человеческое решение, применение, разрешение продолжения, ACK и приёмка DoD остаются отдельными фактами.

Cursor и Claude Code имеют собственные редактор и terminal tools. Read-only ограничение относится к файловым инструментам Ouro и не означает запрет нативных возможностей IDE. Дашборд видит сообщённые по контракту факты; он не перехватывает автоматически каждое действие, изменение файла или внутренние рассуждения клиента. Для наблюдаемой работы агент должен явно отправлять отчёты в Ouro.

## Если не подключается

- **Connection refused:** оставьте Ouro запущенным, дождитесь `Ready`, сверьте порт и точный project URL. Loopback другого компьютера/контейнера не указывает на ваш Ouro.
- **ENOENT или сервер не запускается:** проверьте абсолютные пути Node, bridge и key file с учётом ОС клиента. `~` и незаполненный пример не являются готовым абсолютным путём.
- **401/403:** проверьте, что файл содержит ключ действующей регистрации именно этого проекта, а клиент использует её URL. Регистрация в другом проекте и ключ аккаунта Cursor/Anthropic не заменяют ключ Ouro.
- **Конфиг добавлен, tools не видны:** включите сервер, проверьте trust/permissions и логи MCP; для Desktop полностью перезапустите приложение. JSON нужно объединить с существующим файлом, сохранив валидную структуру.
- **Tools доступны, работа не начинается:** назначьте попытку этой регистрации и обратитесь к агенту в его клиенте. Создание ключа или последнего обращения не запускает модель автоматически.

[ChatGPT через Secure MCP Tunnel](chatgpt-guide.md) остаётся отдельным примером общего контракта. Настройка профиля, локальная SDK-проверка и настоящее подключение установленного пользовательского клиента — разные результаты; фактические проверки приведены в [журнале](plans/client-onboarding.md).

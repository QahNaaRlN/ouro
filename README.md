# Ouro

Human View для агентской разработки: ожидание → исполнение → наблюдение → решение человека → уточнение ожидания.

Репозиторий сейчас содержит проект требований и методологии. Приложение, зависимости, база данных и релизы ещё не созданы. Планируемая первая версия: `0.1.0-alpha.1`; это предложение, а не опубликованный релиз.

- [ТЗ: продукт и Human View](docs/TZ-Ouro-OS.md)
- [ТС: домен, контракты и интеграция](docs/TS-Ouro-OS.md)
- [Статусные модели и неизменяемая история](docs/status-methodology.md)
- [Human ID, Agent ID, контракты и SemVer](docs/ids-contracts.md)
- [Исследование практик графов и источники](docs/graph-research.md)

По уточнению пользователя pen.dev используется как макет Ouro, а стиль берётся из Meridian в Figma. Оба макета пока не прочитаны из-за сетевого ограничения; структура экранов, точные токены и компоненты не извлечены. Ссылки и роли источников зафиксированы в ТЗ. Интеграционный API Meridian также пока не предоставлен.

Исходные документы сохранены без изменений в [docs/source](docs/source/README.md). Приоритет: прямые уточнения пользователя → дополнения в этой редакции → исходные документы. Конкретные технические решения в дополнениях являются проектными предложениями до их согласования и реализации.
